    Evidence index¶

    Manifest of every evidence item in the audit package: where it lives, how it is produced, and how often it refreshes (confidence labels live with each claim in the documents themselves). Rules: pointers for anything regenerable; snapshots only for run results that constitute point-in-time evidence. Evidence produced with content-bearing flags (--include-content) inherits the corpus handling level per docs/governance.md's evaluation-handling rule and must not be committed here — only content-free default reports belong in this repository.
